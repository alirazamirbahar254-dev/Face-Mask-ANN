# Face Mask ANN

Binary Image Classification using Artificial Neural Network (ANN).

## Dataset
Face Mask Dataset with two classes:
- With Mask
- Without Mask

## Dataset Split
- Training: 70%
- Validation: 20%
- Testing: 10%

## Model
Artificial Neural Network (ANN)

## Results
- Test Accuracy: 90.13%
- Test Loss: 0.2498

## Prediction
The trained model successfully predicted a new image as:
**With Mask**
